# VisionPulse development plan

Lifecycle: compact V-model for the initial Android prototype.

Required artifacts: requirements, basic design, detailed design, source, unit/build verification, and manual acceptance checklist. The canonical implementation is GitHub main. Version and build settings are held in this repository. Common APK/signing/CI rules are referenced from the shared Wiki 01/02/03.

Review/approval condition for this initial phase: the user request to build the described Android prototype is treated as approval of the scope below. Any behavior outside that request is excluded.
